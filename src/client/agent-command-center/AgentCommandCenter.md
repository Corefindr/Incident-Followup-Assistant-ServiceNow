# Agent Command Center

The Agent Command Center is the agent-facing work queue for pending caller follow-ups.

Recommended capabilities:

- filter by assigned to me, my group, due, overdue, and repeat cycles
- inline update outcome, summary, next due date, and status
- quick actions for email sent, phone attempted, caller responded, and no response
- display incident number, short description, caller, age, due date, and attempt count
- write structured Incident work notes through the follow-up attempt flow

Do not publish screenshots from a real production instance. Use generated demo records only.
