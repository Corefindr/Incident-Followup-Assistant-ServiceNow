# System Properties

Recommended properties:

| Property | Example | Purpose |
| --- | --- | --- |
| `x_scope.followup.default_due_hours` | `24` | Hours until first follow-up is due |
| `x_scope.followup.due_window_hours` | `4` | Window where a follow-up is considered due |
| `x_scope.followup.overdue_reminders_enabled` | `true` | Toggle reminder notifications |
| `x_scope.followup.max_attempts_before_escalation` | `3` | Threshold for manager attention |
| `x_scope.followup.work_notes_prefix` | `Follow-up Assistant` | Prefix for structured incident work notes |
